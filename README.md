# Rapid Hackathon: Manifest

Team of 4. Three 45-minute problems, one folder each.

| # | Project | Problem | Folder |
| --- | --- | --- | --- |
| 1 | Backup Host | Resy goes down at 2 PM. Rebuild the book, confirm guests, and sync back with zero double bookings. | [01-resy-outage-backup-host](01-resy-outage-backup-host/) |
| 2 | Way Home | Knicks championship night. Map street closures from alerts, posts, and reports, and route people home. | [02-parade-night-way-home](02-parade-night-way-home/) |
| 3 | 911 Call Triage | Call volumes spike after an incident. Find duplicate reports and flag high-priority cases for immediate response. | [03-911-call-triage](03-911-call-triage/) |

## Run project 1

```bash
cd 01-resy-outage-backup-host
pip install -r requirements.txt
streamlit run app.py
```
