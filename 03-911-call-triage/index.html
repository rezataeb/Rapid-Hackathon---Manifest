How it decides

1 · Is this call a duplicate?

Every call is compared with each incident's calls. Five signals add up to a match score from 0 to 1.

Distance to nearest call (full ≤60 m, zero ≥500 m)0.35
Same incident type (related types get partial)0.30
Shared words in transcript and address0.20
Time since the incident's last call0.15
Same callback number as an earlier caller+0.35

≥ 0.65 merged as a duplicate. 0.53–0.65 opened as its own incident but flagged for a dispatcher to merge or keep. Below that, a new incident. Nothing is silently discarded.

2 · How urgent is the incident?

Score = type base + every risk flag heard on any call + a corroboration bonus for multiple callers (up to +15). A duplicate that adds a new flag, like "trapped", re-ranks the incident at once. 70+ P1 Immediate, 45–69 P2 Urgent, below 45 P3 Routine.
